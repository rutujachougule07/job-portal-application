# Burgundy & Champagne Careers

Build a complete, modern, premium and production-ready

JOB PORTAL + E-SALARY APPLICATION.

The platform must support 3 major roles:

1. USER / JOB SEEKER

2. ADMIN / EMPLOYER

3. SUPER ADMIN

The application must be multilingual, mobile-first, responsive, scalable and professionally designed.

IMPORTANT:

This should NOT look like a basic student project or generic job portal template.

The UI should look like a real-world professional employment, recruitment and employee-management platform.
